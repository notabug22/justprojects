# Car Rental Service Analytics (SQL)

## Objective
Analyze booking, pricing, and vehicle utilization data to identify demand patterns and support inventory and pricing decisions.

## Dataset
Structured rental transaction data including:
- Booking dates
- Vehicle categories
- Rental duration
- Pricing information
- Location details

(Note: Dataset used for analytical demonstration purposes.)

## Tools & Techniques
- SQL
- Complex Joins
- Aggregations
- CTEs (Common Table Expressions)
- Window Functions
- Subqueries

## Analysis Performed
- Evaluated vehicle category utilization rates
- Analyzed pricing patterns across locations
- Compared revenue performance by category and time period

## Key Insights
- Certain vehicle categories remained underutilized despite competitive pricing
- Seasonal trends indicated predictable demand spikes
- Revenue concentration varied across rental locations

## Business Value
This analysis demonstrates how structured SQL queries can be used to:
- Optimize inventory allocation
- Support pricing adjustments
- Improve utilization efficiency
- Inform data-driven operational decisions
