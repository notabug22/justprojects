# Real Estate Price Analysis – Indian Metro Cities (Excel)

## Objective
Analyze housing price trends across major Indian metro cities to understand affordability patterns, price distribution, and regional variations.

## Dataset
Structured housing dataset containing:
- City
- Property type
- Price
- Area (sq. ft.)
- Price per sq. ft.
- Configuration details

(Note: Dataset used for analytical demonstration purposes.)

## Tools Used
- Microsoft Excel
- Pivot Tables
- Advanced Formulas
- Power Query (for cleaning and transformation)
- Conditional Formatting
- Interactive Dashboard Design

## Analysis Performed
- Compared average property prices across metro cities
- Evaluated price per square foot distribution
- Identified affordability differences between cities
- Analyzed property type trends

## Key Insights
- Significant variation in price per sq. ft. across metro cities
- Certain cities showed higher premium pricing relative to average area
- Mid-range property categories demonstrated higher transaction concentration

## Business Value
This dashboard demonstrates how Excel can be used for:
- Comparative market analysis
- Regional pricing evaluation
- Data-driven real estate insights
- Interactive reporting for decision support
